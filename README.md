# Molix

**分子 AI 定制服务**

</div>


Molix 是一家专注于分子人工智能的团队。

我们用 AI 技术，帮助药物、材料和化学研发团队
在**合成之前**就能预测分子性质、生成候选分子、筛选最优方案。


## 核心能力

### 🧠 模型训练

- 基于大规模分子数据，训练高精度预测模型。

- 覆盖溶解度、毒性、稳定性、活性等核心性质，根据客户数据定制。

### ⚗️ 分子合成

- 用 AI 辅助设计合成路线，评估可行性与成本。

- 对接合作实验室，完成从设计到合成的闭环。

### 🔍 分子筛选

- 从大规模分子库中快速筛选候选，多性质同时评估。

- 输出优先推荐列表，直接送入实验验证。

### 📊 ADMET 预测

- 全面评估药代动力学与安全性。

- 覆盖吸收、分布、代谢、排泄、毒性五大维度，输出可读的评估报告。
